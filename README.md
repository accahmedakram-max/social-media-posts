# social-media-posts
📲 Social Media Posts Data Cleaning & Reach AnalysisThis repository contains a comprehensive Data Cleaning, Exploratory Data Analysis (EDA), and Data Visualization project performed on social media post datasets across major Middle Eastern cities (Cairo, Dubai, Beirut, Riyadh, Alexandria, Amman, Doha, Jeddah, and Baghdad).📌 Project OverviewThe main goal of this analysis is to inspect raw social media dataset entries, identify and fix data quality issues (such as missing values, extreme outliers, and inconsistent column formats), calculate a consolidated Reach Metric, and analyze audience engagement across different post categories, months, and cities.📊 Dataset StructureThe cleaned dataset consists of 1,011 rows and the following primary attributes:Column HeaderData TypeDescriptionPost_DateFloat / DatetimeSerial Excel date or date stamp of the postYearIntegerYear the content was posted (e.g., 2024, 2025)MonthIntegerMonth of publication (1 to 12)CityStringTarget city locationPost_TypeStringCategory (Educational, News, Tech, Religious, etc.)Post_DetailsStringDescription text of the postLikesFloat / IntTotal count of post likesSharesIntegerTotal count of post sharesCommentsFloat / IntTotal count of post commentsPost_LinkStringURL directing to the published postreach (Engineered)FloatEngineered Total Metric (Likes + Shares + Comments)🛠️ Data Cleaning & Preprocessing WorkflowHandling Outliers:Found an erroneous outlier in Likes (95,760.0 for index 502) and corrected it to 9,576.0.Managing Missing (NaN) Values:Dropped completely invalid / corrupted entries (e.g., Row index 322).Imputed missing values in Likes using the dataset mean.Imputed missing Comments values using targeted subset imputation
